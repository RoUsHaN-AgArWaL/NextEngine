🧠 What is NextEngine?

NextEngine is a privacy-focused desktop web browser built to make everyday browsing faster, cleaner, and more intentional.

It combines a minimal browsing interface with powerful tools such as intelligent search, custom commands, Bangs, privacy controls, reader mode, tasks, bookmarks, keyboard shortcuts, customization, downloads, and NextEngine AI.

The goal is simple:

The browser should adapt to the way you work — not the other way around.

NextEngine is being developed as an independent evolution of the Min browser architecture, with its own identity, interface, features, and product direction.

✨ Why NextEngine?

Most browsers keep adding features until the interface becomes the feature.

NextEngine takes a different approach:

🚀 Features

🔎 Intelligent Search

The address/search interface is designed to understand more than ordinary URLs.

For example:

open youtube

→ opens YouTube

open youtube hlo

→ opens YouTube and searches for hlo

You can also use Bang-style commands:

! youtube

or:

! youtube hlo

The idea is simple:

COMMAND → DESTINATION → QUERY

⚡ Bangs

Bangs turn frequently used destinations into instant commands.

Examples:

!yt cats
!gh react
!mdn fetch
!r programming

Instead of:

open website
→ find search box
→ type query
→ search

you can go directly from intent to destination.

🧩 Custom Bangs

Create your own commands for the websites you use every day.

Example:

!yt   https://youtube.com/search?q=%s
!gh   https://github.com/search?q=%s
!mdn  https://developer.mozilla.org/search?q=%s
!r    https://reddit.com/search?q=%s

Then:

!gh electron

can take you directly to a GitHub search.

⌨️ Keyboard Shortcuts

Power users should not need a mouse for everything.

🧑‍💻 Userscripts

Extend the browser with userscripts.

🔐 Password Auto-Fill

NextEngine includes password-management support designed around a secure and convenient sign-in experience.

The browser can work with its supported password-manager integrations and provides access to saved-password functionality where supported.

Sensitive credentials should never be exposed in the UI.

🚀 Getting Started

Prerequisites

Install:

Node.js

Git

Platform-specific build dependencies when required by Electron/native packages

Clone

git clone https://github.com/RoUsHaN-AgArWaL/NextEngine.git
cd NextEngine

Install dependencies

npm install

Start development mode

npm run start

After making browser-UI changes, use the project's reload shortcut when applicable.

📦 Building

Windows

npm run buildWindows

macOS — Intel

npm run buildMacIntel

macOS — Apple Silicon

npm run buildMacArm

Debian / Linux

npm run buildDebian

Raspberry Pi

npm run buildRaspi

Linux ARM64

npm run buildLinuxArm64

Red Hat

npm run buildRedhat

Availability of a build target depends on the project's current build configuration and required platform dependencies.
